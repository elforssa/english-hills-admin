## Repository evidence and inference

- [Webhook route](../../../src/app/api/webhooks/meta/leads/route.js) passes `CRM_META_APP_SECRET` into [signature verification](../../../src/lib/crm/meta/protocol.mjs); [inbound contract](../../crm-meta-ingestion.md) documents this separate inbound secret. Thus a shared issuing app can couple app-secret recovery to intake. This is code evidence of a dependency, not a fresh read of Production secret presence/value or actual webhook enablement.
- [Lifecycle adapter](../../../src/lib/crm/lifecycle/adapter.mjs), [worker](../../../src/lib/crm/lifecycle/worker.mjs) and [server](../../../src/lib/crm/lifecycle/server.js) send only the resolved token in transient multipart with the fixed host, no-store, redirect rejection and closed server gate. They have no provisioning/debug/revocation service. Adding operator recovery does not justify injecting its secrets into these modules.
- [Migration 106](../../../supabase/migrations/106_crm_lifecycle_provider_contract_r4_seed.sql) binds exact five events, v26 and no-uncertain-replay. [H3-04 release](crm-h3-04-production-2026-10-02.md) is inherited Production verification, not repeated here.
- **Inference:** C2 separates app-secret recovery and full-app assignment from the intake app, materially improving that failure boundary; it adds a new app/secret/access surface and does not establish narrow scopes, extra System User capacity or independent human-account security. C1 is smaller but shares that failure boundary.
- **Remaining architecture evidence gaps:** B1’s one supported bounded sending/app/dataset grant contract and B4’s selected independent invalidation path/authority. Current evidence does not establish `ads_read`, `ads_management`, `business_management`, Page/Instagram permissions or ad-account authority as necessary for CRM sending. B2 capacity and B3 app setup/status are later fail-closed preflight gates; B5 external custody is an owner decision requiring no Meta confirmation. The [classified register](../plans/historical/crm-h3-05-option-c-amendment.md#provider-blockers-and-closure-evidence) governs closure. No credential/event experiment was performed.
