# Implementation task

Inputs: coherent outcome and acceptance criteria, risk tier/rationale, approved scope, repository plan/revision and recorded owner decisions when architecture is required, current-main baseline and dedicated branch. Read [AGENTS](../../../AGENTS.md), the approved repository contract, relevant ADRs and durable product/security/workflow docs directly; the owner should not need to relay them between chats.

1. Verify current main and reconcile intervening implementation/migrations against the contract. Apply [outcome-based batching](../../../AGENTS.md#outcome-based-batching): keep evidence and corrections serving this outcome together; obtain missing decisions for genuine scope/design/security changes or actions outside authorization.
2. Implement approved scope with local Supabase, synthetic fixtures and external email disabled. Confirm deployment evidence before allocating forward migrations; never edit deployed migrations or use Production secrets/data. Preserve finance/conversion invariants and other-role denials.
3. Run focused checks and explicitly required validation under [findings-driven validation](../../../AGENTS.md#findings-driven-review-and-validation). Add positive/negative, concurrency or browser coverage appropriate to changed behavior. Update durable docs only for changed facts, distinguishing implementation, merge, deployment and Production verification.
4. Perform the [single focused author self-check](../../../AGENTS.md#author-self-check-before-handoff), inspect the final/staged diff, stage explicit paths, commit/push and open/update one PR. Do not spawn an internal reviewer or issue an independent-review verdict.
5. Confirm remote CI scheduling, then stop polling and hand off under [CI selection and remote-CI handoff](../../../AGENTS.md#ci-selection-and-remote-ci-handoff). The coordinator verifies terminal exact-SHA CI before a separate independent Tier-2/Tier-3 review. Fix reviewer findings on this same branch and follow the same validation/handoff policy; no merge or release authority follows.

Return the fields and exactly one status required by [implementation handoff](../../../AGENTS.md#implementation-handoff): branch, exact head/base, PR, tier/rationale, plan revision, applicable migration manifest, local tested SHA/tree, checks/run links and synthetic merge evidence when available, author self-check, documentation and blockers/owner decisions. Preserve merge/release holds separately. For scheduled but unfinished CI use **AUTHOR WORK COMPLETE — REMOTE CI PENDING**; this is not review readiness.

Lane eligibility and job results follow the [CI routing contract](../../architecture/plans/ci-tooling-fast-path.md). Risk tier is independent of CI workload; lightweight policy checks do not waive independent review or owner/Production gates.
